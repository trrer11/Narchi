Stand 25.08.2026. **Kein Marketing.** Was Sie wirklich tun.

## Start

1. Docker Desktop läuft.  
2. `1_DEMARRER_NARCHI.bat` (erster Start) oder `2_REDEMARRER_NARCHI_RAPIDE.bat`.  
3. Edge: http://localhost:8080 — Konto anlegen.  
4. **Nie** `4_TOUT_EFFACER` auf echten Daten.

## Checkliste

| Schritt | Wo |
|---|---|
| Projekt anlegen oder Beispielprojekt | Projekte |
| Impressum (Name, Straße, PLZ/Ort, E-Mail) | Einstellungen |
| Absender Rechnung (Name, USt-IdNr, IBAN) | Rechnungen |
| NGF > 0 (tippen oder aus IFC speichern) | DIN 276 / Import |
| IFC ablegen, speichern | 3D-Import |
| Auftraggeber-Anschrift | Projekte |

## Typischer Ablauf

IFC → Speichern → DIN 276 ansehen → Clash auf Qualität → HOAI aus NGF → Rechnung Entwurf → PDF/A-3.  
Scope-Guard (Büro-Management): Vertrag vs. « noch schnell ».  
IQ: erst Werkzeuge, optional « Lokal erklären » (Ollama, kein Cloud).

## Grenzen (bleiben)

HOAI = Orientierung. DIN-Kennwerte = Richtwerte. Clash ≠ Solibri. Peppol-Netz = nein.  
Zwei Stundenbücher: HOAI-Projektstunden und Büro-Zeiterfassung — nicht dasselbe.
